# germany-archive-channel

German-language archive documentary channel about Germany 1945-1970 (Wiederaufbau, Luftbrücke,
Wirtschaftswunder, everyday life in the FRG and the GDR). Engine copied from the Yesterday in Color
engine (archive-channel) and being adapted.

Status: setup (channel_brief.md). Automation is OFF: the production workflows sit in `workflows_off/`
until the owner approves the pilot episode. Licences: only PD, CC0, CC BY.
